# Contribution Guidelines

This is a community project and any contributions are more than welcome!

However, please follow these guidelines:

- Test your submissions on either macOS or/and Linux (and please state on which OS you did testing). Everything should work correctly on both platforms.
- Make sure that `swift-format` is properly set up on your editor of choice. Xcode does not have format-on-save so do not forget before committing.

## AI

If you use AI to help you, you take full responsibility for the contribution. This means that any PR including code that isn't tested and doesn't work, or is clearly "vibe coded", will be closed.

**Do not** contribute comments/documentation for this project that are written with AI.

Also, please avoid AI generating PR descriptions or commits.
